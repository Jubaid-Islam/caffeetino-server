# Caffeetino Server

Backend API for the Caffeetino coffee web store, responsible for authentication, product management, order processing, payments, and secure data handling.

## Features

- JWT-based authentication and authorization with Firebase Admin SDK.
- RESTful APIs for products, carts, wishlists, orders, and user management.
- Secure Stripe payment integration with server-side payment verification.
- Automatic stock updates after successful order placement or cancellation.
- Optimized MongoDB operations for fast and reliable data management.

## Tech Stack

- Node.js
- Express.js
- MongoDB
- Firebase Admin SDK
- JWT (JSON Web Token)
- Stripe
- CORS
- Cookie Parser
- Dotenv


## Core Modules

- Authentication
- User Management
- Product Management
- Shopping Cart

- Payment Processing
- Stock Management
